# ValutaTrade Hub

Учебный валютный кошелёк — этапы 2.1 (модели) и 2.2 (CLI).
Автор: David Zakharyan, группа М26-555.
Репозиторий: `finalproject_Zakharyan_M26-555`.

Реализованы пользователи, валютные кошельки, портфели, регистрация и вход,
виртуальные покупки и продажи, кеш учебных курсов. Все деньги виртуальные.
Parser Service с реальными API и расписанием будет добавлен на следующих этапах.

## Установка

Требования: Python 3.12+, uv. Из корня проекта:

```bash
uv sync --locked --dev
uv run valutatrade
```

Альтернативы: `uv run python main.py` или `make install` / `make run`.
CLI установленного пакета называется `valutatrade`.

## Пример

Команды выполняются внутри приложения. Для учебной демонстрации можно
использовать пароль `1234`; открытый пароль в JSON не сохраняется.

```text
register --username alice --password 1234
login --username alice --password 1234
show-portfolio
deposit --amount 5000
get-rate --from USD --to BTC
buy --currency BTC --amount 0.05
show-portfolio
sell --currency BTC --amount 0.01
show-portfolio --base EUR
logout
exit
```

Повторный запуск требует нового `login`, но кошельки и пользователь сохраняются.
Имена с пробелами можно заключать в кавычки. `help` показывает команды.

## Правила операций

- Регистрация создаёт **пустой** портфель; имя уникально с учётом регистра.
- `deposit --amount ...` — согласованное дополнение к заданию для пополнения
  виртуального USD-кошелька. Без него пустой портфель не смог бы покупать валюту.
- `buy --amount` задаёт количество покупаемой валюты, а не сумму USD.
  Покупка списывает `amount * rate` из USD и зачисляет валюту.
- `sell` списывает валюту и начисляет USD. Продажа или покупка USD за USD
  не поддерживается: это не обмен. Для внесения USD используется `deposit`.
- Ошибка курса, недостаточный баланс и ошибочная сумма не сохраняют изменения
  в портфель. Комиссий и внешних денежных переводов нет.
- `show-portfolio`, `deposit`, `buy`, `sell` требуют входа. `get-rate` общедоступна.
- Валюты нормализуются в верхний регистр. Суммы должны быть конечными числами
  больше нуля. `bool`, NaN, бесконечность и отрицательные балансы запрещены.
- Балансы представлены `float`, как требует задание. Это учебная модель,
  а не расчётная система для реальных денежных операций.

## Модели

`User(user_id, username, hashed_password, salt, registration_date)` принимает
сохранённые поля. Для регистрации используется `User.create(id, username, password)`.
Есть свойства для всех атрибутов; имя можно изменять с проверкой, пароль — только
через `change_password`. `get_user_info()` возвращает словарь без хеша и соли.
Пароль хешируется по учебному правилу SHA-256(password + salt); случайная соль
сохраняется рядом с хешем и обновляется при смене пароля.

`Wallet(currency_code, balance=0.0)` проверяет баланс, пополнение и снятие.
`get_balance_info()` возвращает словарь с кодом валюты и балансом.

`Portfolio(user_id, wallets=None, *, user, exchange_rates=None)` принимает
объект владельца явно, чтобы свойство `user` возвращало именно `User`.
Свойство `wallets` возвращает копию словаря (объекты Wallet доступны для работы).
`add_currency` запрещает дубликаты. `get_total_value(base_currency='USD')`
использует фиксированные курсы: `exchange_rates` — словарь цены каждой валюты
в USD. CLI считает отчёт через RateService для использования свежего кеша.

## Курсы и хранение

Текущие учебные курсы в USD: EUR — 1.0786, BTC — 59337.21,
RUB — 0.01016, ETH — 3720.0, USD — 1.0.
Это фиксированная **заглушка**, а не актуальные котировки. Источник `DemoStub`
показывается в CLI. Время обновления обозначает время получения учебного значения.

`RateService.get_rate(from_currency, to_currency)` возвращает словарь:
`from`, `to`, `rate`, `updated_at`, `source`.
Сначала используется кеш моложе 300 секунд: прямая пара, обратная или кросс-курс
через USD. Иначе вызывается заменяемый provider и обновляется кеш.
Поставщик принимает два кода валют и возвращает `rate`, `updated_at`, `source`.
Будущий Parser Service можно подключить через этот контракт.

При первом запуске автоматически создаются:

```text
data/users.json       # Пользователи с хешами, солями и датами
data/portfolios.json  # Кошельки, сгруппированные по user_id
data/rates.json       # Последние котировки и время обновления
```

Папка `data` считается от текущей директории запуска; всегда запускайте приложение
из одной папки для работы с той же базой. Рабочие JSON-файлы исключены из Git.
Каждый документ записывается через временный файл и `os.replace`. Изменения обоих
кошельков при сделке сохраняются одной заменой `portfolios.json`. При регистрации
есть откат при ошибке сохранения второго документа; полноценные транзакции
между файлами и одновременная запись из нескольких процессов не реализованы.

## Проверки и сборка

```bash
make lint
make test
make build
uvx twine check dist/*
uv tool install --force dist/valutatrade_hub-0.1.0-py3-none-any.whl
valutatrade
```

Тесты используют временные папки и не меняют рабочие данные. Они проверяют
модели, пароли, типы, сделки, изоляцию пользователей, восстановление после
перезапуска, кеш и недоступность курсов.
